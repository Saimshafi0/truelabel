# Truelabel

Website for **Truelabel**, a Shopify app for printing barcode, QR code and price labels at the exact size of Avery sheets and DYMO, Zebra and Brother rolls.

- Home: `index.html`
- Support and FAQ: `support.html`
- Privacy policy: `privacy.html`

## About the app
Built with React Router, the Shopify Admin GraphQL API, Prisma and the Shopify Billing API.

- Label engine that lays out labels in millimetres and renders the same layout to the screen and to PDF, so the preview matches the print
- Barcodes (EAN-13, UPC-A, Code 128) and QR codes, with thermal-printer dot alignment
- Duplicate and missing barcode detection with unique code generation saved back to Shopify
- Pattern-based SKU generator with collision checks
- Admin link extensions to print from the Products list and product pages
- Plan limits with monthly usage tracking and Shopify billing
- Seven interface languages

Built by Saim Shafi.
